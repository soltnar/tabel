АВТОНОМНЫЙ ЗАПУСК НА WINDOWS 10/11

1. Полностью распакуйте ZIP-архив.
2. Откройте распакованную папку Tabel.
3. Дважды нажмите Tabel.exe.
4. Дождитесь автоматического открытия браузера.

Python, pip и права администратора не требуются.

Важно:
- не запускайте Tabel.exe прямо внутри ZIP-архива;
- не переносите отдельно Tabel.exe без остальных файлов папки;
- для остановки приложения закройте черное окно запуска;
- если Windows SmartScreen покажет предупреждение, выберите
  "Подробнее" -> "Выполнить в любом случае".

Приложение открывается по адресу:
http://localhost:8000
