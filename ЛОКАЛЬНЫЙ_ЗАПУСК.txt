ГЕНЕРАТОР ГРАФИКА СОТРУДНИКОВ
================================

WINDOWS 10/11: ЗАПУСК ОДНИМ ФАЙЛОМ
----------------------------------
1. Полностью распакуйте ZIP-архив в обычную папку.
2. Дважды нажмите START_WINDOWS.bat.
3. Разрешите Windows запуск файла, если появится стандартное предупреждение.
4. Дождитесь открытия страницы http://localhost:8000.

При первом запуске START_WINDOWS.bat автоматически:
- найдет установленный Python 3.11;
- при его отсутствии установит Python через winget;
- если winget недоступен, загрузит подписанный установщик с python.org;
- создаст отдельное окружение .venv-windows;
- установит все библиотеки приложения;
- запустит сервер и откроет браузер.

На первом запуске нужен интернет. Последующие запуски не требуют повторной
установки Python и библиотек.

ВАЖНО
-----
Не открывайте static/index.html напрямую: без локального сервера интерфейс
работать не будет.

ОСТАНОВКА
---------
Закройте окно приложения или нажмите Ctrl+C.

ДАННЫЕ
------
Файлы обрабатываются локально на компьютере. Результаты находятся в папке
outputs и доступны через кнопки скачивания в интерфейсе.

macOS
-----
Для запуска на macOS дважды нажмите start.command.
